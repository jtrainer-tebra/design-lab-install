Installer for the Tebra SaaS Design Lab.
Ask Jay for access.

Balance Design Lab starts with the Balance project and includes the Lab editors,
prototype engines, design skills, and a fresh Tolaria vault.
Ask Jay for access to the private Balance repository before installing on an
Apple Silicon Mac. Then run this in Terminal:

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/jtrainer-tebra/design-lab-install/main/install-balance.sh)"
```

Open `~/Balance Design Lab` in Codex after installation. Double-click
`start-lab.command` to reopen the Lab. For later releases, ask Codex to
"update my lab" so the updater can preserve your work.
